# Frontend

Vite + React SPA on Vercel. Root context: `../AGENTS.md`, `../docs/technical/frontend.md`.

## Commands

From `frontend/`:

- Install: `npm ci`
- Dev: `npm run dev` (port 3000)
- Test: `npm test` (Vitest)
- Lint: `npm run lint`
- Build: `npm run build`

Polish UI copy is preserve. Cold-start lamp: ADR-19 (`useApiHealthProbe`), not a keep-alive pulse.
